# Changelog

## 0.1.0 candidate —2026-11-14

- Local Tehran Network companion with real LTE telemetry and session history.
- Persian RTL/English, dark/light, mobile, keyboard and reduced-motion support.
- Native-menu bridge with session renewal and genuine backend role checks.
- Native primary account and SUPER password workflow, encrypted backup and
  narrow account recovery. SUPER rename remains unsupported.
- PowerShell/CMD modes, compatibility guards, regression tests and sanitized
  browser evidence from one physical owner device.
- No firmware replacement or new RF bands. Final release is pending owner review.
# 0.3.0 — Native modem workspace

- Replace the old iframe with same-device controls styled inside our workspace.
- Add 27 main menus, hidden presentation controls for verified SUPER, full
  available telemetry, hardware report, colored traffic and signal histories.
- Add measured, cell-aware antenna alignment with CSV export and neutral arrows
  when evidence is insufficient. Handle fresh SIM state and stale WAN identity.
- Ignore late authentication failures from a previous session after an account switch.
- Add encrypted, device-bound native WebUI installation and UI-only rollback.
  Keep all passwords, firmware, RF/calibration and working APN settings unchanged.
