# سازگاری مبتنی بر شواهد

پروفایل مجاز: نام Backend برابر `ZLT P19H`، سخت‌افزار `TZ7.821.183` یا نگارش
همان برد با پسوندB، و فریمور دقیق `3.2.27`. برچسب P11 به تنهایی کافی نیست.
برد فیزیکی مالک P19H_OUTDOOR_CPE.PCB است؛ بخش رادیویی Sequans S16 دارد.

مدل، نسخه و نقش قبل از عملیات بررسی می‌شوند. دستگاه ناسازگار هیچ تغییر حساب،
ریست یا نوشتن رادیویی دریافت نمی‌کند. از تغییر Allowlist برای عبور اجباری از
بررسی خودداری کنید؛ ابتدا روی دستگاه دیگر آزمایش مستقل و بکاپ معتبر لازم است.

پشتیبانی قابل‌مشاهدهٔ رادیویی B42 و B43 است؛ B42 با مبین‌نت آزمایش شده و B43
تنها اعلام شده است. FDD، همراه اول، سیم‌کارت همراه ایرانسل یا اپتل عملاً آزمایش
نشده‌اند. رفع محدودیت نرم‌افزاری اپراتور، باند سخت‌افزاری جدید ایجاد نمی‌کند.

فقط یک دستگاه فیزیکی آزمایش شده است. آزمون‌های شبیه‌سازی، CI و طراحی Responsive
جای آزمون مودم دوم یا دسترسی از یک گوشی دیگر در LAN را نمی‌گیرند. نسخهٔ عرضه‌شده
عمداً loopback است؛ انتشار آن روی IP عمومی یا شبکهٔ نامطمئن پشتیبانی نمی‌شود.
