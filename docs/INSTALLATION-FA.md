# نصب و حالت‌های اجرا

نیازمندی: Windows10/11، Python3.10+، مرورگر جدید، اتصال اترنت به مودم. اجرا با
کاربر معمولی ویندوز کافی است. هیچ وابستگی runtime از pip یا CDN دریافت نمی‌شود.
Python را جداگانه از python.org نصب کنید؛ این بسته runtime ناشناخته دانلود نمی‌کند.

۱. پروژه را خارج از پوشهٔ بکاپ‌های خصوصی استخراج کنید.
۲. `installer/install.cmd --check` را اجرا کنید. این حالت فقط پروفایل را می‌خواند.
۳. `installer/install.cmd --install` را اجرا کنید؛ نام و رمز فعلی در ورودی مخفی
پرسیده می‌شوند. رمز را به آرگومان فرمان تبدیل نکنید.
۴. پنل محلی در مرورگر باز می‌شود. با حساب واقعی دستگاه وارد شوید. کنسول باید
باز بماند؛ Ctrl+C برنامه را می‌بندد. پورت پیش‌فرض 8765 است؛ با `--port 0`
پورت آزاد انتخاب می‌شود. آدرس را با `--router 192.168.0.254` می‌توان تعیین کرد.
گزینهٔ `--router auto` فقط آدرس شناخته‌شده و دروازه‌های پیش‌فرض تنظیم‌شدهٔ ویندوز
را بررسی می‌کند؛ محدودهٔ شبکه اسکن نمی‌شود و Routeها تغییر نمی‌کنند.

`--dry-run` ورود و وضعیت را می‌خواند و تنظیم حساب، ریست یا فریمور نمی‌نویسد.
`--backup` خروجی بومی را اعتبارسنجی، رمزگذاری و دوباره باز می‌کند.
`--verify` ورود و WAN/Band را بررسی می‌کند؛ تست سرعت یا صحت اینترنت خارجی نیست.
`--apply-accounts` فقط همراه نصب، Wizard حساب‌های پشتیبانی‌شده را باز می‌کند.
`--verify --reboot-check` تنها یک ریست و آزمون ورود/WAN پس از آن انجام می‌دهد؛
این گزینه عمداً اتصال را برای مدت کوتاه قطع می‌کند و پیش‌فرض فعال نیست.

نسخهٔ PowerShell معادل `-Mode`، `-ApplyAccounts`، `-RebootCheck`، `-Router`،
`-Port` و `-NoBrowser` دارد. نمونه:

```powershell
.\installer\install.ps1 -Mode install -ApplyAccounts
.\installer\verify.ps1 -RebootCheck
```

بکاپ‌ها و Journalها زیر `%LOCALAPPDATA%\TehranNetwork\P19H` و به صورت `.dpapi`
قرار می‌گیرند؛ فایل را حذف نکنید. بازیابی به همان کاربر ویندوز و همان مودم
فیزیکی وابسته است. بکاپ خام و اطلاعات ورود در مخزن قرار نمی‌گیرند.

دانلود Release با بررسی SHA256 پس از ساخت و انتشار واقعی آن مستند خواهد شد.
تا آن مرحله، نصب از checkout/بستهٔ بررسی‌شده انجام می‌شود؛ فرمان `iex` یا URL
ساختگی برای اجرای کد دریافت‌شده ارائه نمی‌شود.
