# رابط مستقیم تهران نتورک 0.3 برای P19H

این نسخه از حافظهٔ خود مودم اجرا می‌شود. برنامهٔ کامپیوتر فقط برای نصب اولیه
و بکاپ لازم است. فریمور رادیو، کالیبراسیون و رمزهای وب و SSH تغییر نمی‌کنند.

- ۲۷ منوی اصلی، زیرمنوهای شبکه/APN/DHCP، فایروال، حساب، گزارش و ابزارها در
  محیط خودمان نمایش داده می‌شوند؛ iframe و پیوند ورود به پنل قدیمی وجود ندارد.
- صفحه‌های قدیمی index، login، info، home و نسخه‌های ذخیره‌شدهٔ vendor به
  `/tehnet/index.html` هدایت می‌شوند. فایل‌های کنترل بومی فقط از همان مودم خوانده
  می‌شوند و در بستهٔ عمومی بازنشر نشده‌اند.
- سوپرادمین گزینه‌های مخفی‌شدهٔ ظاهری را می‌بیند. پرچم پشتیبانی سخت‌افزار و
  مجوزهای سرور حفظ می‌شوند؛ وجود نام یک قابلیت، اثبات پشتیبانی یا فعال‌شدن آن نیست.
- گزارش کامل، داده‌های موجود PLMN، IMSI، IMEI، ICCID، RX/TX، بسته‌ها، آدرس‌ها،
  نسخه‌ها، باند/EARFCN، RSSI، RSRP، RSRQ، SINR، MCS/CQI و پرچم‌ها را نشان می‌دهد.
  دادهٔ گزارش‌نشده خالی می‌ماند. اسرار ورود در جدول عمومی تشخیص نمایش داده نمی‌شوند.
- نمودارهای رنگی فقط از نمونه‌های واقعی ساخته می‌شوند. نمودار ترافیک، مصرف
  مشاهده‌شده است؛ آزمون سقف سرعت نیست. میله‌های آنتن تخمینی از RSRP هستند.
- راهنمای جهت‌دهی، نمونهٔ مبنا و حرکت‌های برچسب‌خوردهٔ کاربر را مقایسه می‌کند.
  بدون چند نمونهٔ معتبر روی باند و سلول ثابت، جهت چپ/راست/بالا/پایین حدس زده نمی‌شود.
- فارسی RTL، انگلیسی، پوستهٔ روشن/تاریک، موبایل و کاهش حرکت پشتیبانی می‌شوند.

## نصب از سورس

Windows و Python 3.10+ و اتصال اترنت لازم‌اند. فقط پروفایل
`ZLT P19H / TZ7.821.183[B] / 3.2.27 / sqn/32x0` مجاز است. حساب SUPER معتبر باید
از قبل به کنسول فرمان بومی دسترسی داشته باشد. نصب‌کننده رمز SSH را بازیابی یا
حدس نمی‌زند و هیچ رمز مشترکی ندارد.

```powershell
python -X utf8 -m tehnet.native_install --check
python -X utf8 -m tehnet.native_install --install
```

نام و رمز فعلی هنگام نصب پرسیده می‌شوند. پیش از جایگزینی، تنظیمات PAC و درخت
وب بکاپ گرفته، صحت انتقال بررسی و بکاپ با Windows DPAPI خارج از checkout ذخیره
می‌شود. نسخهٔ قبلی در `/root/tehnet-backups`، خارج از مسیر وب، حفظ می‌شود. فایل‌های
نصب‌شده از HTTP دوباره خوانده و مقایسه می‌شوند. عملیات نامشخص خودکار تکرار نمی‌شود.

```powershell
python -X utf8 -m tehnet.native_install --rollback "PATH-TO-native-JOURNAL.dpapi"
```

بازگردانی به همان دستگاه و همان کاربر ویندوز متصل است؛ اگر رابط پس از نصب عوض
شده باشد، بازگردانی کور انجام نمی‌شود. تنظیمات و حساب‌های بعدی با بکاپ قدیمی
بازنویسی نمی‌شوند. بکاپ وب/PAC جای بکاپ کامل SPI، NV یا راه نجات سخت‌افزاری را نمی‌گیرد.

## محدودهٔ تأیید

آزمون واقعی روی یک مودم مالک انجام شده است: ۲۷ منوی اصلی، ۴۰ زیرزبانه، گزارش
سیستم، نمونه‌برداری جهت‌دهی، لغو عملیات و چیدمان موبایل. آزمون نمایش منو به معنی
اجرای ریست، فلش یا همهٔ تغییرات تنظیمات نیست. برخی صفحات مخفی در همین فریمور
پیاده‌سازی نشده‌اند و مقدار/کنترل کاربردی برنمی‌گردانند.

انتقال نهایی بستهٔ بزرگ روی دستگاه مالک با SSH تأییدشده انجام شد. انتقال قطعه‌ای
CGI، تبدیل باینری Lua و فعال‌سازی نصب‌کننده نیز بررسی شدند؛ نصب کامل از صفر روی
مودم دوم آزمایش نشده است. مسیر انتقال محدودیت BusyBox و نبود base64 را در نظر می‌گیرد.

روی سیم Mobinnet360 مالک، ثبت شبکه و اینترنت از خود مودم تأیید شد. نام اپراتور
از وضعیت تازهٔ سیم/شبکه خوانده می‌شود؛ بعد از تعویض سیم به برچسب ورود قدیمی تکیه
نمی‌شود. تغییر سیم باید با خاموش‌کردن و جاگذاری صحیح انجام شود؛ این نصب‌کننده
APN سالم یا پروفایل سازمانی دستگاه‌های دیگر را بازنویسی نمی‌کند.

این بسته آنلاک همگانی رادیو نیست. افزودن UI، B3/FDD یا سازگاری با هر سیم‌کارتی
را ثابت نمی‌کند. فایل جدید معتبر برای این برد تأیید نشده و فلش ناشناس غیرفعال است.
نصب بدون ریبوت است؛ در فریمور مالک، تغییر خودکار رمز SSH هنگام بوت قبلاً مشاهده
شده است. این بسته سیاست بوت فروشنده یا رمز SSH را تغییر نمی‌دهد.
