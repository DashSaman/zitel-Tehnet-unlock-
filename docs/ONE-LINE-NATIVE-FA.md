# نصب مستقیم با یک فرمان

Windows، Python 3.10+، اتصال اترنت و نام/رمز SUPER فعلی لازم‌اند. حساب باید از
قبل کنسول بومی مجاز داشته باشد؛ این دستور رمز SSH را نمی‌شکند. بسته فقط برای
P19H/TZ7.821.183[B]/3.2.27/sqn/32x0 است و پیش از نصب دوباره مشخصات را بررسی می‌کند.

فرمان زیر در CMD و PowerShell قابل اجراست. کد از مخزن همین پروژه دریافت می‌شود؛
نصب‌کننده SHA256 بسته را پیش از اجرای آن بررسی می‌کند و برای ورود، رمز فعلی
خود دستگاه را می‌پرسد. هیچ رمز مشترک یا رمز زندهٔ مودم مالک در بسته نیست.

```text
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/DashSaman/zitel-Tehnet-unlock-/main/installer/bootstrap-native.ps1'))) -Mode install"
```

برای بررسی مدل بدون ورود یا تغییر تنظیمات، انتهای دستور را به `-Mode check`
تغییر دهید. ExecutionPolicy فقط برای همین فرایند است و سیاست دائمی ویندوز
عوض نمی‌شود. نصب‌کننده ابزار یا Python جدیدی را خودکار نصب نمی‌کند.

بکاپ وب و تنظیمات و Journal با Windows DPAPI در پروفایل کاربر ذخیره می‌شوند.
تا پایان عملیات برنامه را نبندید. اگر قطع شد یا نتیجه نامشخص بود، دستور را
کورکورانه تکرار نکنید؛ ابتدا Journal را بررسی کنید. [بازگردانی](NATIVE-WEBUI-FA.md)
فقط رابط همان دستگاه را برمی‌گرداند و رمزها یا تنظیمات بعدی را بازنویسی نمی‌کند.

نصب UI، فعال‌کردن FDD یا اینترنت با هر سیم‌کارت نیست. حالت خودکار APN و امکان
خدمت‌گیری به سرویس سیم، پوشش و RF واقعی دستگاه بستگی دارد. نصب روی مودم دوم
آزمایش نشده است؛ تغییرات رادیویی ناشناخته و کالیبراسیون بخشی از این بسته نیستند.
