# بکاپ اصلی مالک و بازگشت آینده به زیتل

بکاپ اختصاصی این دستگاه به صورت رمزگذاری‌شده در
[شاخهٔ owner-recovery](https://github.com/DashSaman/zitel-Tehnet-unlock-/tree/owner-recovery)
نگهداری می‌شود. این شاخه با بستهٔ نصب عمومی متفاوت است و فایل‌های خام دستگاه
یا کلید بازیابی را منتشر نمی‌کند.

داخل بسته، تصویر کامل SPI به اندازهٔ ۳۲ MiB از دو خواندن مستقل و یکسان، آرشیو
وب اصلی زیتل و محتوای واقعی صفحه‌های ورودی وجود دارند. تصویر SPI مربوط به قبل
از تغییر رمز root و نصب UI است. وب اصلی بعد از بازیابی حساب و قبل از تعویض UI
ثبت شده است. «تنظیمات کارخانهٔ دست‌نخورده» ادعا نشده است.

کلید تصادفی جداگانه در فایل خصوصی `OWNER-RECOVERY-KEY.txt` به مالک تحویل داده
می‌شود. این کلید با رمزهای مودم متفاوت است و هیچ رمز مودمی برای ساخت بکاپ تغییر
نکرده است. کلید روی گیت‌هاب نیست؛ یک نسخهٔ مستقل از آن نگه دارید. رمزگشایی به
کاربر یا ویندوز قبلی وابسته نیست و به کلید نیاز دارد.

در آن شاخه، `Restore-Backup.ps1 -VerifyOnly` صحت بکاپ را آفلاین و بدون نوشتن فایل
خام بررسی می‌کند. خروجی ZIP خصوصی هم قابل تولید است. اسکریپت به مودم وصل نمی‌شود،
پنل فعلی را تغییر نمی‌دهد و هیچ فلشی انجام نمی‌دهد.

برای برگرداندن ظاهر زیتل، فایل‌های وب و ورودی اصلی برای همان مودم موجودند؛
بازیابی واقعی باید با تطبیق دستگاه و بکاپ وضعیت روز انجام شود. تصویر کامل SPI
فایل Upgrade سازنده نیست و نباید از فرم ارتقای وب آپلود شود. بازگردانی کامل آن
ممکن است تنظیمات و حساب‌ها را به زمان بکاپ برگرداند؛ بازیابی فقط UI مستقل است.
