# بستهٔ آمادهٔ بازبینی مالک

این نسخه یک Companion محلی برای P19H3.2.27 است و فریمور داخل مودم را جایگزین
نمی‌کند. نام و رمز حساب عادی اصلی، و رمز SUPER از مسیر بومی قابل مدیریت‌اند؛
تغییر نام SUPER پشتیبانی نمی‌شود. این محدودیت باید پیش از انتشار نهایی روشن بماند.

قابلیت‌های اصلی: دادهٔ واقعی LTE، نمودارهای نشست، فارسی/انگلیسی، پوستهٔ روشن/
تاریک، موبایل، منوهای اصلی، Wizard محافظت‌شده، بکاپ DPAPI و Rollback محدود.

فقط مودم فیزیکی مالک آزمایش شده است. آزمون‌ها، مدارک مرورگر، ماندگاری پس از
ریست و بازیابی در docs موجودند. تصاویر از نام حساب و شناسه‌ها پاک‌سازی شده‌اند.
اطلاعات ورود واقعی در این بسته وجود ندارد.

این Release تا پیش از بازبینی مالک **Draft** می‌ماند. انتشار خودکار عمومی یا
فرمان دانلود و اجرای جعلی در پروژه قرار نگرفته است. SHA256SUMS.txt برای ZIP
همراه ساخته می‌شود؛ مالک باید هش مورد انتظار را از یک منبع قابل اعتماد بردارد
و پیش از اجرای اسکریپت مقایسه کند. دریافت ZIP و هش از یک محل، امضای مستقل نیست.
