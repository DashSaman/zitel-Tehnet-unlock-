# اعتبارسنجی نسخهٔ کاندید

۳۰ آزمون واحد و مرزی در Windows/Python3.12 موفق‌اند: پروتکل Challenge، نقش و
خواندن محافظت‌شده، تطابق مدل/فریمور، ورودی ناقص، Host/Origin/CSRF/Cookie، انقضای
نشست و خروج هم‌زمان، کدک PAC و خرابی چک‌سام، DPAPI واقعی ویندوز، تغییر و بازگردانی
محدود حساب، نتیجهٔ نامشخص نوشتن و عدم بازاجرای ریست. فایل‌های PowerShell با Parser
خود PowerShell و JavaScript با Node بررسی شده‌اند.

مرورگر Chromium روی مودم فیزیکی مالک: ورود عادی/مدیر، نمودار دادهٔ واقعی، فارسی/
انگلیسی، تاریک/روشن، عرض موبایل بدون اسکرول افقی، کاهش حرکت، منوی اصلی و ادامهٔ
پایش پس از تمدید Session. تنظیمات ۱۷۷‌تایی پیش و پس از آزمون UI یکسان بود.
مدرک: LIVE-VERIFICATION.json. تصاویر اسکرین‌شات واقعی با نام/شناسه‌های پاک‌شده‌اند.

یک راه‌اندازی مجددِ مأموریت، ورود هر دو نقش، نبود مجوز مدیر برای کاربر عادی،
ماندگاری ۱۷۷ مقدار و بازگشت WAN را تأیید کرد: PERSISTENCE-VERIFICATION.json.

بازیابی واقعی: نام حساب اصلی برای آزمون موقتاً تغییر کرد، ورود تازه تأیید شد،
سپس Rollback محدود از Journal رمزگذاری‌شده نام قبلی را برگرداند. رمز، رادیو و
فریمور تغییر نکرد و ۱۷۷ مقدار دقیقاً با پیش از آزمون یکسان بود:
ROLLBACK-VERIFICATION.json. این آزمون روی حساب موردنظر مالک تمام شد.

پس از ریست، آزمون شبکه با Socketهای مقید به رابط اترنت مودم انجام شد: پینگ
دروازه،۱.۱.۱.۱ و۸.۸.۸.۸ هرکدام۵ پاسخ از۵؛ DNS از مودم و دو مقصد عمومی موفق؛
HTTPS با گواهی معتبر موفق. Route و Adapter ویندوز تغییر نکردند. این آزمون، تست
سرعت یا تضمین کیفیت دائمی اتصال نیست.

اسکن الگوهای اطلاعات حساس، فایل‌های ممنوع، ارجاع مجوزها، و بررسی جداگانهٔ مقدارهای
واقعیِ خصوصی مالک روی سورس و ZIP انجام شده است. هیچ رمز واقعی، هش اختصاصی یا
شناسهٔ دستگاه در بستهٔ عمومی قرار ندارد. بکاپ/Journal فقط در محل خصوصی‌اند.

CI برای Windows/Linux و Python3.10/3.13 تعریف شده است؛ نتیجهٔ اجرای ابری فقط
پس از Push و مشاهدهٔ خود GitHub گزارش می‌شود. هیچ نصب فیزیکی روی مودم دوم،
جایگزینی دائمی UI داخل مودم، تغییر نام SUPER یا پشتیبانی FDD ادعا نشده است.
